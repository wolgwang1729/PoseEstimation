# Satellite Pose Estimation with Deep Landmark Regression and Nonlinear Pose Refinement Implementation files description

These Python Jupyter Notebooks are the implementation of Satellite Pose Estimation with Deep Landmark Regression and Nonlinear Pose Refinement as described in "Satellite Pose Estimation with Deep Landmark Regression and Nonlinear Pose Refinement" (https://arxiv.org/abs/1908.11542). 

## [bochenkeypoint.ipynb](bochenkeypoint.ipynb)
This notebook contains the implementation of the deep landmark regression model for satellite pose estimation. 

## [training.logs](training.logs)
This file contains the training logs for the model, including epoch information, loss values, and accuracy metrics.
