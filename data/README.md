# Data setup (SPEED / SPEED+ - not committed)

Datasets are **not** in git (size + license). Download separately, then arrange as below.

## Download

* SPEED (synthetic 12k + real test): https://kelvins.esa.int/satellite-pose-estimation-challenge/ and https://github.com/tpark94/SPEED
* SPEED+ (synthetic + lightbox + sunlamp domain-gap splits): https://github.com/tpark94/SPEED-Plus
* **My Kaggle mirrors + splits (recommended for repro): see [`docs/kaggle.md`](../docs/kaggle.md)** -
  e.g. `wolgwang/speedsplit`, `wolgwang/mat-file`, `wolgwang/speeddatasetforyolo`, `wolgwang/speed`.

## Expected layout

```text
data/
  speed/
    images/
      train/            # SPEED synthetic train
      test_synthetic/
      test_real/        # 5-image sample + full real split where available
    labels/
      train.json
      test.json
    camera.json         # intrinsics
    tango_points.txt    # 3D keypoints (11 used in pvnet/, 8 in early ablations)
  speed_plus/
    synthetic/
    lightbox/
    sunlamp/
  yolo_dataset/         # generated by yolo/creatingdatasetforyolo.ipynb
    images/{train,val}
    labels/{train,val}
```

Notes:

* Original notebooks expect 1920×1200 mono JPEGs + quaternion (scalar-first) + translation labels.
* `hrnet/` additionally expects `data/PE/` layout - see `hrnet/training.logs` header (`DATASET: PEdataset, ROOT: data/PE/`).
* YOLO config lives at `../yolo/training_metrics/custom_dataset.yaml` - edit its `path:` to point at your local `data/yolo_dataset`.
* Never commit downloaded images: they are already ignored via `.gitignore` (`data/speed/`, `data/yolo_dataset/`).
